# Ovi Plus cloud safety

This Render deployment is paper-trading only.

- PAPER_TRADING=true
- SIGNING_ENABLED=false
- BROADCAST_ENABLED=false
- TAKE_PROFIT remains +17%
- STOP LOSS remains disabled
- Wallet private keys must not be committed to GitHub or the APK.

Render Free web services can restart and have ephemeral local storage. This deployment is for cloud architecture/testing, not production live-money execution.
